# 🚀 Social Media Planner

A robust backend application built with **Spring Boot** and **PostgreSQL** designed to efficiently schedule, manage, and organize social media posts and content workflows.

---

## 🔗 Live Demo
* **Access the Live Application:** [https://social-media-planner-production-49ad.up.railway.app](https://social-media-planner-production-49ad.up.railway.app)

---

## 🛠️ Tech Stack & Tools
* **Backend:** Java, Spring Boot, Spring Data JPA, Hibernate
* **Database:** PostgreSQL
* **Containerization:** Docker
* **API Testing:** Postman
* **Deployment:** Railway

---

## ✨ Features
* **Content Management:** Create, update, view, and delete scheduled social media posts.
* **Database Integration:** Secure and optimized CRUD operations backed by PostgreSQL and Hibernate ORM.
* **RESTful APIs:** Clean architecture adhering to best industry practices for smooth frontend/client communication.
* **Cloud Hosted:** Fully deployed and running live on cloud infrastructure.
